# Ansible Configuration Management Lab

> Automate server configuration and repetitive operational tasks.

## Overview

Managing multiple servers manually can lead to inconsistent configurations and repetitive work.

Ansible provides a way to automate configuration management through declarative playbooks.

This project explores how to configure and maintain Linux servers consistently.

## Learning Objectives

- Understand configuration management.
- Explore Ansible architecture.
- Configure inventories.
- Execute ad-hoc commands.
- Create YAML playbooks.
- Understand tasks, handlers, and variables.
- Use Jinja2 templates.
- Organize reusable roles.
- Understand idempotency.
- Automate server provisioning and configuration.

## Practical Labs

| Lab             | Description                        |
| --------------- | ---------------------------------- |
| Inventory       | Define and organize target hosts   |
| Connectivity    | Test remote host access            |
| Ad-hoc Commands | Execute basic administrative tasks |
| Playbooks       | Automate server configuration      |
| Variables       | Reuse configuration values         |
| Templates       | Generate configuration files       |
| Roles           | Organize reusable automation       |
| Idempotency     | Verify repeatable execution        |

## Automation Projects

Create playbooks to:

- Install and configure Nginx.
- Create users and groups.
- Configure SSH.
- Install required packages.
- Manage system services.
- Configure a basic application server.
- Apply basic Linux hardening.
